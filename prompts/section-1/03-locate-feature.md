# 1.3 Locate a feature

**Goal:** go from a behaviour a user sees to the files that implement it.
**Time:** about 10 minutes.

Paste:

```
Use the code-explorer agent and the locate-feature skill. A customer has forgotten their password and asks the shop to let them set a new one. Where in the code is that behaviour implemented? Start from the HTTP route and end at the data. Tell me which files I would need to read, in call order, and which files look related but are not part of this feature.
```

**Then, on your own:** open the first and the last file in the list and check that each does what the agent says.

**Stretch (if time allows):** repeat with "a customer subscribes to the newsletter".
