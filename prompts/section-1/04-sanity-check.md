# 1.4 Sanity-check the agent

**Goal:** see how an agent's numbers can be wrong, and how to catch it.
**Time:** about 10 minutes.

Paste, one at a time:

```
How many REST endpoints does this shop expose? Give the number, the command you used, and a list grouped by controller.
```

```
How many repository classes does the data layer have? Count them, then count them again a different way, and tell me if the two numbers differ and why.
```

```
Which endpoints in the product API are actually live? Check that none of the ones you listed is commented out.
```

**Then, on your own:** for each answer, decide whether you would put the number in a document. What would you check first?
